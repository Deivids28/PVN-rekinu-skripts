PVN Rēķinu Kalkulators

Python skripts, kas rēķina PVN no rēķinu summām. Uztaisīju to, mācoties programmēt.

Ievadi summu un kategoriju, un programma parāda:

cik no summas ir PVN (21%)
cik ir summa bez PVN

Repo ir divas versijas. Pirmā (pvn_kalkulators_csv.py) saglabā datus CSV failā. Otrā (pvn_kalkulators_sql.py) saglabā datus īstā SQL datubāzē, lai iemācītos, kā Python un SQL strādā kopā.

Taisīts ar Python.
